## What each page contains

Each page folder contains the exact source `mung.xml`, its annotation canvas (`image.png` or `image.jpg`), the accompanying original scan, a sanitized `workflow.json`, and a README preview. Node IDs, class spellings, masks, edges, time-group membership, text, and detector provenance are preserved. Images have not been resized. Source XML and images are byte-identical to the captured files.

Workflow files contain stage states and status provenance without user identities, activity logs, or edit history. This export does not include derived conversion-review sidecars. The source XML is not Stephen’s target score JSON.

The [manifest](manifest.json) lists every page, file size, SHA-256 checksum, image dimensions, status, and count. [Validation notes](VALIDATION.md) describe structural checks and any source-data limitations. This is a fixed snapshot; later edits in MuNGStudio require a new export.
